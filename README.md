# midproject_ksh

LibGDX 2D 플랫포머 (3 레벨)

## 조작
- 방향키 좌우: 이동
- SPACE: 점프
- P / ESC: 일시정지, 재개
- R (1초 누르기): 현재 레벨 재시작
- ENTER: 모든 레벨 클리어 후 처음부터 다시

## 실행
Android Studio Gradle 탭에서 `lwjgl3 > Tasks > application > run`

또는 `demo/midproject_ksh_demo.jar` 다운로드 후 `java -jar midproject_ksh_demo.jar`
